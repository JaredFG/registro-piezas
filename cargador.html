Carga de piezas desde Excel

1. Acceso a la base de datos

Elige el archivo JSON de la clave de servicio del proyecto. Se lee solo en este navegador y se usa únicamente para conectarse a Firebase; no se guarda ni se sube a ningún otro lugar.

2. Archivo de Excel

Una fila por pieza. Columnas obligatorias: Pieza, Estándar y Cliente. Opcionales: Folio, OP, Material, Cantidad, Factura, Fecha factura, Tarima o caja, Estibable, Una sola pieza, Mas piezas encima, Fecha liberacion, Comentarios, Operador, Equipo. Si el archivo tiene cualquier error no se sube nada y se muestra cada problema con su fila.
